# Drone Simulation Starter

This is a small Unity starter project for a physics-based quadcopter scene.

## Open It

1. Open this folder in Unity Hub or run `open-with-unity.ps1`.
2. Let Unity resolve packages. The project includes MCP for Unity:
   `https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main`
3. In Unity, open `Window -> MCP for Unity` and choose `Configure All Detected Clients`.
4. If the starter scene is not already present, run `Drone Sim -> Create Starter Scene`.
5. Press Play.

## Controls

- `W/S`: pitch forward/back
- `A/D`: roll left/right
- `Q/E`: yaw
- `Space/Left Ctrl`: throttle up/down
- `R`: reset drone
- `C`: switch camera distance

## Goal

Fly through the cyan gates. The HUD shows speed, altitude, and gate count.
